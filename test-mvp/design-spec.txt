# NetEase Cloud Music (网易云音乐) UI Design Specification

## 1. Color Scheme

### Primary Colors
| Token | Color | Hex | Usage |
|-------|-------|-----|-------|
| `--color-primary` | Primary Red | `#C20C0C` | Main brand color, active navigation, buttons |
| `--color-primary-hover` | Bright Red | `#D43C33` | Hover states, interactive elements |
| `--color-primary-light` | Soft Red | `#EC4141` | Secondary interactions, badges |
| `--color-primary-pale` | Pale Red | `#FCF0F0` | Active backgrounds, subtle highlights |

### Background Colors
| Token | Color | Hex | Usage |
|-------|-------|-----|-------|
| `--color-bg-primary` | Pure White | `#FFFFFF` | Main content background |
| `--color-bg-secondary` | Light Gray | `#F5F5F5` | Page background, sidebar |
| `--color-bg-tertiary` | Dark Gray | `#EFEFEF` | Hover backgrounds, dividers |
| `--color-bg-player` | Dark Charcoal | `#2A2A2A` | Bottom player bar |

### Text Colors
| Token | Color | Hex | Usage |
|-------|-------|-----|-------|
| `--color-text-primary` | Deep Charcoal | `#333333` | Main headings, titles |
| `--color-text-secondary` | Medium Gray | `#666666` | Secondary text, descriptions |
| `--color-text-tertiary` | Light Gray | `#999999` | Tertiary info, timestamps |
| `--color-text-inverse` | White | `#FFFFFF` | Text on dark backgrounds |

### Border & Line Colors
| Token | Color | Hex | Usage |
|-------|-------|-----|-------|
| `--color-border` | Light Border | `#E4E4E4` | Borders, separators |
| `--color-border-light` | Subtle Border | `#F0F0F0` | Card borders, dividers |

## 2. Layout Structure

### Overall Layout (App Shell)
```
┌─────────────────────────────────────────────────────┐
│  Header (72px) - Search, User, Nav                  │
├──────────┬──────────────────────────────────────────┤
│          │                                         │
│ Sidebar  │        Main Content Area                 │
│ (200px)  │        (flexible width)                  │
│          │                                         │
│          │                                         │
├──────────┴──────────────────────────────────────────┤
│  Player Bar (72px) - Controls, Volume, Progress     │
└─────────────────────────────────────────────────────┘
```

### Sidebar Navigation
- **Width**: 200px
- **Background**: `#EDEDED`
- **Navigation Items**:
  - Discover (发现音乐)
  - Podcast (播客)
  - Friends (朋友)
  - Mall (商城)
  - Musicians (音乐人)
  
- **My Music Section**:
  - Local Music (本地与下载)
  - Recently Played (最近播放)
  - My Favorites (我喜欢的音乐)
  - Created Playlists
  - Subscribed Playlists

- **Active State**: Red left border `#C20C0C` + red text
- **Hover State**: Light background `#E4E4E4`

### Header (72px)
- **Background**: Pure white `#FFFFFF`
- **Components**:
  - App navigation tabs (Discover, Podcast, Friends, etc.)
  - Search bar (centered)
  - User avatar and message/notifications
  - Skin settings

### Main Content Area
- **Background**: `#F5F5F5` or white content containers
- **Padding**: 20px-30px
- **Content Organization**:
  - Section headers with "more >" links
  - Grid-based playlists
  - Horizontal carousels for featured content
  - Recommended artists
  - New song releases

### Bottom Player Bar (72px)
- **Height**: 72px
- **Background**: Gradient `#2A2A2A` to `#232323`
- **Layout**: Three-column flex layout
  
  **Left Column (Progress & Song Info) - 20%**
  - Album artwork (48x48px)
  - Song title + artist name
  - Like button (heart icon)
  - Download button
  
  **Center Column (Controls) - 60%**
  - Play mode shuffle/single/loop icon
  - Previous track button
  - Play/Pause button (large circle)
  - Next track button
  - Volume control button
  - Progress bar with time info
  
  **Right Column (Extras) - 20%**
  - Current volume level
  - Lyrics button
  - Playlist button
  - Comments count badge

## 3. Key UI Components

### Playlist Card
```
┌──────────────────────┐
│ ┌──────────────────┐ │
│ │   Cover Image    │  ← 200x200px, rounded corners
│ │   [Play count]   │  ← overlaid top-right with eye icon
│ │   [Play button]  │  ← green play icon, appears on hover
│ └──────────────────┘ │
│ └──────────────────┘ │
│ Playlist Title        │
│ Creator/Description   │
└──────────────────────┘
```
- **Card Background**: `#FFFFFF`
- **Shadow**: `0 2px 8px rgba(0,0,0,0.08)` hover
- **Hover Effect**: Slight lift + shadow
- **Play Button Hover**: Circular play overlay with `#C20C0C` background

### Song List Item (in table row)
```
┌─────────────────────────────────────────────────────┐
│ # │ Title | Artist | Album | Duration | Actions      │
├─────────────────────────────────────────────────────┤
│ 1 │ Song  │ Artist│ Album │ 4:23     │ Like ▶ │ More│
│ 2 │ Song  │ Artist│ Album │ 3:45     │ Like ▶ │ More│
└─────────────────────────────────────────────────────┘
```
- **Row Height**: 40px
- **Header Row**: Background `#EFEFEF`
- **Hover State**: Background `#F5F5F5`
- **Playing State**: Red text `#C20C0C`
- **Actions on hover**: Show like, play, and more options

### Player Controls Button
- **Play/Pause**: Large circle button, red background `#C20C0C` hover `#D43C33`
- **Previous/Next**: Icon buttons, subtle gray background
- **Progress Bar**: Thin line `#444444` with red fill `#C20C0C` and white handle
- **Volume**: Slider control with speaker icon

### Navigation Tab
- **Normal**: Text `#666666`, transparent background
- **Hover**: Text `#333333`
- **Active**: Text `#FFFFFF` (dark header) or `#C20C0C` (light header), bottom red border

### Button Components
- **Primary**: Background `#C20C0C`, text white, rounded 4px
- **Secondary**: Border `#C20C0C`, text `#C20C0C`, transparent background, rounded 4px
- **Ghost**: No background/border, icon only

## 4. Design Characteristics

### Visual Style
- **Clean and Functional**: Minimal decorative elements, focus on content
- **Music-Centric**: Album artwork and cover images prominently displayed
- **Consistent Red Accent**: Red color appears throughout as the action color
- **Information-Dense**: Content-rich layout with efficient use of space

### Typography
- **Chinese-Optimized**: Uses system Chinese fonts (PingFang SC, Microsoft YaHei)
- **Font Sizes**: 12-16px body, 18-24px headings, section titles 24-28px
- **Font Weights**: 400 (Regular), 500 (Medium), 600 (Semi-bold)

### Interaction Patterns
- **Hover Reveals**: Play buttons, action menus appear on hover
- **Direct Playback**: One-click play from any content card
- **Mini Player**: Persistent bottom bar with progress and controls
- **Red as Action Color**: All primary actions highlighted in red

## 5. Responsive Considerations
- **Desktop Primary**: 1200px+ width
- **Minimum Width**: 1000px for full sidebar experience
- **Content Scales**: Grid columns adjust from 5 to 3 cards based on space
