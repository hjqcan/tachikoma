# Handoff Template

Use this template for worker-to-worker or worker-to-orchestrator updates.

```
Objective:
Findings:
Changes:
Files:
Blockers:
Next:
```

## Example
```
Objective: Add OAuth login
Findings: Existing auth module uses JWT only
Changes: Added oauth config, updated routes
Files: packages/auth/oauth.ts, packages/auth/routes.ts
Blockers: Awaiting client id
Next: Add docs and tests
```
